# แมพ: ลานวัดร้าง (Temple Courtyard)

ลานหินสี่เหลี่ยม 200x200 studs มีกำแพงรอบ (สูง 26) และกำแพงล่องหนเหนือกำแพงกันโดนกระเด็นออกนอกแมพ
รองรับผู้เล่น 2-8 คน ใช้ Part พื้นฐานทั้งหมด ไม่มีภาพ/เสียงจากภายนอก

## ผังจากด้านบน (ทิศเหนือ = -Z)

- กลางลาน: แท่นหินกลม 2 ชั้น + รูปปั้นหักพังทรงนามธรรม (ใช้เป็นที่กำบัง)
- เสา 8 ต้น สูงต่างกัน (10/14/24) ใช้หลบสกิลและเล่นเกมแดช
- แท่นสูง 8 studs ทิศเหนือและใต้ มีทางลาด 2 ข้าง และซุ้มไม้หลังคาแดง
- กองหินกำบังเตี้ย 4 จุด ฝั่งตะวันออก/ตะวันตก
- จุดเกิด 8 จุด: มุมลาน 4, กลางกำแพงตะวันออก/ตก 2, บนแท่นสูง 2 (ForceField 3 วินาที)

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/shared/Maps/TempleCourtyard/Layout.luau` | ตำแหน่ง/ขนาดชิ้นส่วน จุดเกิด ขอบเขตลาน (ข้อมูลล้วน) |
| `src/shared/Maps/TempleCourtyard/Theme.luau` | สี วัสดุ แสง (แก้หน้าตาที่นี่ที่เดียว) |
| `src/server/MapBuilder.luau` | สร้างแมพจาก Layout + Theme ลง `Workspace.Map` |
| `src/server/MapLoader.server.luau` | เรียกสร้างแมพตอนเซิร์ฟเวอร์เริ่ม ลบ Baseplate และปิดจุดเกิดเดิมของเทมเพลต |

## สำหรับระบบอื่น

- ชิ้นที่ใช้หลบได้ติดแท็ก `ArenaCover` (CollectionService) เผื่อทำของพังได้ในอนาคต
- `Workspace.Map` มี attribute `BoundsMin` / `BoundsMax` ให้ระบบต่อสู้เช็กว่าตำแหน่งอยู่ในลาน
- กำแพงล่องหนตั้ง `CanQuery = false` จึงไม่บัง raycast/hitbox ของสกิล

## ลองใน Studio

1. ติดตั้งปลั๊กอิน Rojo ใน Studio แล้วรัน `rojo serve` ในโฟลเดอร์ repo
2. กด Connect ในปลั๊กอิน Rojo
3. กด Play แมพจะถูกสร้างอัตโนมัติ (ตอนยังไม่กด Play จะไม่เห็นแมพ เพราะสร้างด้วยสคริปต์)
