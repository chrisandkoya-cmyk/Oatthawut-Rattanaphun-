# ติดตั้ง Rojo และเปิดเกมใน Roblox Studio (สำหรับมือใหม่)

Rojo คือตัวเชื่อมระหว่างโค้ดใน GitHub กับ Roblox Studio ทำให้โค้ดในโฟลเดอร์ `src/` ไปโผล่ใน Studio เอง

## ครั้งแรกครั้งเดียว
1. **ดาวน์โหลดโปรเจกต์** จาก GitHub: กดปุ่มเขียว *Code → Download ZIP* แล้วแตกไฟล์ (หรือใช้ `git clone` ถ้าใช้เป็น)
2. **ติดตั้งปลั๊กอิน Rojo ใน Studio**
   - เปิด Roblox Studio → แท็บ *Plugins* → *Manage Plugins* → ค้นหา "Rojo" (ของ Rojo / Roblox-rojo) แล้วติดตั้ง
   - หรือดาวน์โหลดจาก https://rojo.space/docs/v7/getting-started/installation/
3. **ติดตั้งโปรแกรม Rojo (ตัวรัน)** ที่ https://github.com/rojo-rbx/rojo/releases (เลือกเวอร์ชัน 7.4.4 ตามระบบของคุณ: Windows = `rojo-7.4.4-windows-x86_64.zip`) แตกไฟล์แล้ววาง `rojo.exe` ไว้ที่ที่หาเจอ เช่น `C:\Rojo\`

## ทุกครั้งที่จะเล่น/เทส
1. เปิด Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วรัน: `rojo serve`
2. เปิด Roblox Studio → สร้างแมพใหม่ (*Baseplate*) หรือเปิดแมพของคุณ
3. แท็บ *Plugins* → กดปุ่ม **Rojo** → **Connect**
4. โค้ดจะซิงก์เข้ามา: `ReplicatedStorage/Shared`, `ServerScriptService/Server`, `StarterPlayerScripts/Client`
5. กด **Play** (F5) แล้วลองตี

> วิธีไม่ต้องใช้ `rojo serve`: รัน `rojo build -o AnimeArena.rbxl` จะได้ไฟล์เกม เปิดด้วย Studio ได้เลย

## ปุ่มควบคุม
| ปุ่ม | ทำอะไร |
|---|---|
| คลิกซ้าย | M1 คอมโบ 4 หมัด (หมัดที่ 4 ผลักไกล) |
| กด **Space ค้าง** แล้วคลิก | อัปเปอร์คัต ตีเป้าขึ้นฟ้า |
| **กระโดดแล้วคลิก** (ปล่อย Space ก่อนคลิก) | ทุบลงพื้น เป้ากระแทกพื้นแล้วเด้งกลับ (ถ้ายังกด Space ค้างอยู่ตอนคลิก จะกลายเป็นตีเสยแทน) |
| F (ค้าง) | บล็อก (ด้านหน้า การ์ดมีความทนจำกัด ทะลุแล้วแตก) |
| Q | แดช (กดทิศเดินพร้อมกันเพื่อเลือกทิศ) |
| 1 2 3 4 | สกิล |
| G | อันติ (เกจต้องเต็ม) |

มือถือ: ปุ่มบนหน้าจอเรียงวงโค้งรอบปุ่มกระโดดของ Roblox — ตี (ปัดขึ้น = ตีเสย, แตะกลางอากาศ = ตีกด), การ์ด (กดค้าง), แดช (ตอนโดนมึนและเกจพอ ปุ่มจะเป็น "หลุด!" = เบิร์สต์), อันติ, สกิล 1-4 (2x2) เกจอันติอยู่บนจอ ตำแหน่งปุ่มทั้งหมดอยู่ที่ `src/client/UI/TouchLayout.luau`

ใน Studio จะมีหุ่นซ้อม 2 ตัวเกิดข้างจุดเกิด (ตัวหนึ่งยืนเฉยๆ อีกตัวบล็อกตลอด) และเห็นกล่อง hitbox สีแดง ปิดได้ใน `src/shared/Config.luau` (`Debug`)
